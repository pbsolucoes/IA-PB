# Funil comercial (modelo)

> ⚠️ O repositório é público. Aqui fica **só a estrutura**. A lista real de contatos fica numa planilha privada (Google Drive).

| Etapa | Definição | Ação do agente comercial | Meta semanal |
|---|---|---|---|
| 1. Alvo | Clínica que se encaixa no perfil (segmento + porte) | Pesquisar dados públicos | ✏️ |
| 2. Abordado | Recebeu a 1ª mensagem | Mensagem personalizada | ✏️ |
| 3. Conversa | Respondeu e aceitou conversar | Roteiro do diagnóstico | ✏️ |
| 4. Diagnóstico | Conversa de diagnóstico da gestão realizada | Resumo + pedido de proposta | ✏️ |
| 5. Proposta | Proposta enviada | **redator-propostas** | ✏️ |
| 6. Cliente | Contrato assinado | **juridico-contratos** + implantação | ✏️ |
